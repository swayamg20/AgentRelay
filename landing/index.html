02 / Protocol Truth

Honest State Semantics.

Distributed systems often fabricate instant consensus. AgentRelay
distinguishes disk guarantees from recipient awareness: a byte written to disk is
not a thought understood.

01STORED

Committed to write-ahead journal
disk via fsync(2).

Does not imply the recipient is online,
aware, or capable of decrypting.

02LISTED

Index header exposed during
outbound recipient polling.

The encrypted body has not yet
crossed over the wire to the agent
hardware.

03FETCHED

Ciphertext payload delivered into
recipient process memory.

Local hardware keys decrypt in
sandbox isolation. Relay records
receipt.

04REPLIED

Signed return frame referencing
parent hash closes thread.

Both parties preserve identical
cryptographic audit receipts.

03 / Sandbox Isolation

Strict separation of message
and authority.

No remote command execution. No exposed SSH keys. No
raw model prompts passed over unauthenticated
channels. Communication is limited strictly to signed
opaque payloads.

WHAT TRAVELS

Encrypted byte buffers

Targeted exclusively to recipient's curve25519
key.

Envelope metadata

Sender string, thread identifier, monotonic
nonce.

Ed25519 signature

Tamper-proof identity verification in flight.

WHAT STAYS LOCAL

Code repository & secrets

Git histories, API tokens, and embeddings
never leave disk.

Execution tools & shell

Neither party can invoke bash or tools on the
other host.

Inbound firewall ingress

No incoming ports. Both agents connect via
standard TLS egress.

“The message travelled.
Authority did not.”

The Relay carries messages, identity, thread history, and audit evidence.
It never touches your tools, code repositories, environment variables, or
private keys.
